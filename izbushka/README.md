# Избушка на курьих ножках (LEGO, ~15 см)

Схема сборки модели избушки Бабы-Яги из **системных деталей LEGO® — без элементов Technic**.
Высота готовой модели ≈ 15 см (47 пластин), 95 деталей, 13 шагов сборки.

## Результаты (папка `out/`)

| Файл | Что это |
|---|---|
| `out/izbushka_instructions.pdf` | Пошаговая схема сборки (16 страниц: обложка, спецификация, 13 шагов, готовая модель) |
| `out/izbushka_final.png` | Финальное изображение собранной модели |
| `out/pages/page_XX.png` | Все страницы схемы отдельными PNG |

## Как пересобрать

```bash
python3 -m venv .venv
.venv/bin/pip install pillow
.venv/bin/python izbushka/make_instructions.py
```

## Состав модели

* **Курьи ножки** — 2 стопы (пластины 2×4 + 3 ската «сыр» на каждой), голени из брусков 2×2,
  «колени» из пластин 2×3 со смещением (визуальный изгиб ноги).
* **Платформа** 8×8 из пластин 4×4 (2 слоя), с выпусками по периметру.
* **Стены** — 5 венцов внахлёст (рубка сруба), дверной проём 2×3, два окна из прозрачных брусков.
* **Крыша** — шатровая: свес 8×8, пояс скатов 45° (детали 3039/3045), верхняя пирамида из
  угловых скатов, шпиль-конус. Кирпичная труба с дымом проходит сквозь пояс скатов.

Все детали — только системные (Classic/System): бруски, пластины, скаты, плиты, конус.
